# Civil Procedure II Ultimate Reviewer

GitHub Pages-ready static reviewer.

## Files

- `index.html` — Ultimate CivPro II reviewer
- `flowchart.html` — visual master flowchart
- `assets/images/` — poster and reviewer images
- `assets/videos/` — optional small local videos

## GitHub Pages

Publish from the default branch and the repository root.

## Videos

Small MP4 files can be placed in `assets/videos/`.

For longer lectures, use YouTube embeds to avoid making the repository unnecessarily large.
